High-Throughput Mitochondrial Genomic Showcase

Welcome to the interactive showcase for mitochondrial DNA (mtDNA) variant calling, gap alignment standardization, pairwise distance matrix calculation, and phylogenetic reconstruction derived from 43 sequencing read alignment datasets (`.bp` / `.blast`) mapped against the revised Cambridge Reference Sequence (rCRS, 16,569 bp).

Genomic Pipeline Architecture

1. Gap Alignment Standardization: Standardizes gap positioning towards lower coordinates (`align_gaps_to_lower_coordinate`), accounting for strand bias on forward (+) and reverse (-) reads.
2. Variant Quality Control: Enforces minimum read depth, strand bias ratio thresholding (< 0.80), homopolymer run detection, and edge bias filtering.
3. Pairwise VAF Distance: Calculates pairwise Manhattan distances \(d(S_i, S_j) = \sum |VAF_{i,p} - VAF_{j,p}|\) across all 43 sample variant profiles.

Pipeline Methodology & Algorithmic Equations

1. Gap Shift Standardizer

Alignments near homopolymer tracks or indels often introduce arbitrary gap placement. align_gaps_to_lower_coordinate shifts gaps deterministically towards lower coordinates (5' for + strand, 3' for - strand).

2. Manhattan VAF Distance

Pairwise distance between two samples \(S_i\) and \(S_j\) is defined as the absolute VAF difference sum across all mutated loci:
d(S_i, S_j) = ∑ |VAF_{i,p} - VAF_{j,p}|

3. Quality Control Filter Rules

Strand bias ratio filter tags variants with > 0.80 read bias on one strand. Clonal amplification filter flags identical reads exceeding 20% total depth.
